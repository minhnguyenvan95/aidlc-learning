# Operations — AI-DLC Interactive Walkthrough

## Trạng thái: Không áp dụng

Dự án này là trang web tĩnh (static site), không cần:
- Triển khai server
- Giám sát
- CI/CD pipeline
- Quản lý incident

## Cách phân phối
- Copy thư mục `aidlc-docs/` (chứa index.html, styles.css, app.js)
- Mở `index.html` trong trình duyệt bất kỳ
- Hoặc host trên GitHub Pages / Netlify / bất kỳ static hosting nào
